# Documents

Déposer ici les exports Markdown des documents de conception, avec ces noms :

1. `GDD.md` : Game Design Document v0.2
2. `TDD.md` : Technical Design Document v0.1
3. `BDS.md` : Balancing Design Specification v0.1
4. `schemas-donnees.md` : schémas JSON
5. `script-15-premieres-minutes.md`
6. `script-phase-2.md`
7. `maquettes/` : captures des écrans

Les valeurs chiffrées de ces documents sont reprises dans `data/` ; en cas d'écart, `data/` fait foi.
